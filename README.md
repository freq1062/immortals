# Immortals SMP Mod

## Overview

This mod is made for Fabric 1.21.4 and soon 1.21.8. It might work in 1.21+, but I haven't tested it. Note that you need this installed server and client side for the custom items to work.

In the Immortals SMP a conflict is constantly occurring between two factions: the Mortals and the Immortals. Mortals have access to a lifesteal system and have technology themed custom weapons like the Phasebreaker and Chronoreaver. Immortals have access to a new "corruption" system which grants magical powers such as Dash, Blackout, permanent strength/speed, and immunity to being one-shot.

To become immortal, craft a totem + ascension relic found in ancient cities, fortresses, and ominous vaults. You cannot go back to being mortal.

Installing the mod Tickrate is recommended.
