# Immortals SMP Mod

**In this server there are two types of players: Mortals and Immortals.** Written for the Immortals SMP, a private Minecraft server. 
[Season 3 Showcase Video](https://youtu.be/vRI8XWS1vNA?si=LfgPW5n38ARcN1Yd)

## Overview

The season 3 version of this mod is for Fabric 1.21.4. The season 4 version of this mod is for Fabric 1.21.8. They aren't the same, season 4 has improved client-side visuals, bugfixes, and more.
In both versions, the mod must be installed server and client side. 

Installing the mod [Tickrate](https://modrinth.com/mod/tick) is recommended.

## Features

In the Immortals SMP a conflict is constantly occurring between two factions: the Mortals and the Immortals. Mortals have access to a lifesteal system and have technology themed custom weapons like the Phasebreaker and Chronoreaver. Immortals have access to a new "corruption" system which grants magical powers such as Dash, Blackout, permanent strength/speed, and immunity to being one-shot.

To become immortal, craft a totem + ascension relic found in ancient cities, fortresses, and ominous vaults. You cannot go back to being mortal.

A full spell system for Immortals, use /bind -slot- -spellid- to bind a spell to a slot. In the Season 4 version, you can set a custom keybind to activate the spell. Shifting+right clicking always works, although you must have an item in your offhand or mainhand.

The Null Space dimension is a new dimension that contains all the "bugs" and "unwanted" features of Minecraft. Giants, zombie horses, illusioners, killer bunnies spawn in the Desert of Time, and mobs are frozen in the Broken Plains. 

See the showcase video for more detailed descriptions on what abilities are available to Mortals and Immortals!

## What I learned

This was the first Minecraft Mod I created. I decided that making this would be a good exercise to learn Java, which I needed to know for CSC207. I learned how to make custom items, blocks, dimensions, textures, custom network and rendering APIs, Mixins, the Gradle and Maven workflows, version control, GUI rendering, Video editing, and more. 

At one point I wanted to host the server on an old laptop, so I learned how to install Ubuntu, use bash, and create a docker container for a Minecraft server. I also learned how to SSH into a VPS and create a network tunnel between my laptop and the external VPS to not expose my actual IP and get around university firewalls. It turns out that the bandwidth is really bad, though so that went nowhere. Oh well ):

The server also ended in Season 4 because another owner was abusing and generally power hungry. But the memories and the friends that I gained from this server will always stay with me.
